## The hammer button is missing

The builder button is the hammer icon in the page header. If it is missing, start the backend with `ajs project dev` and sign in as a tenant owner. Under `ajs project start`, the builder is off by default.

Do not turn the builder on in a deployment only to bring the button back. With `api.enabled: true`, tenant owners can rewrite the sources of that environment.

## Every /api/builder route answers 404

The builder is off in this process, so the module never imports its routes controller. [When the builder is on](/docs/modules/builder/configuration#when-the-builder-is-on) lists the commands that turn it on.

## Save fails with "stale"

The page changed on disk after you opened it. Another editor, the AI assistant or a hand edit wrote to it. The banner offers three actions. **Copy my draft** copies your draft as JSON. **Keep my version** reads the page again and keeps your draft, so your next **Save** writes it over those changes. **Reload the page** drops your draft.

## Save fails on the typecheck

The builder writes only code that compiles across the whole project. If a save fails with `typecheck_failed`, nothing is written, and the error lists each diagnostic with its file and line. A type error elsewhere in the project also blocks the write, even when your edit did not cause it. Fix that error first, then save again.

## A chart reads nothing from its old route

The DMS serves the routes of a page under `/dms/pages<page path>`, not at the page's own path. A data source the builder wrote answers at that address. A block whose `fetchUrl` names the page's own path (`/shop/board/stats/revenue`) gets no data.

To fix the block, point its `fetchUrl` at `/dms/pages/shop/board/stats/revenue`. `pageRoutePath(page, endpoint)` from `@antelopejs/interface-dms/page` builds that path. In the [Data workspace](/docs/modules/builder/usage/data-sources#the-data-workspace), **Answers at** shows the URL of the source, and **Used by** lists the blocks that read it.

## A block shows as a stand-in on the canvas

The preview cannot build the block faithfully, for example a table the running app has not loaded. Save the page and let the backend reload. The block then renders from the running page.

## A role lost access to a block I moved

The DMS names a block permission after the place where the block sits. Moving or renaming a block gives it a new permission. The change list warns about this before you save. To restore access, grant the new permission to the role in **Roles**.

## Where does the builder write?

The builder writes under `projectRoot`, in the project's own sources:

- pages as `PageController` classes,
- tables as `Table`, `DataController` and model files,
- data sources as model methods and page routes.

Commit these files like any other code.
